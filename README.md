## ◈ Projetos em Destaque

<details>
<summary><strong>Louas.UI.Framework</strong> — Biblioteca Customizada de UI/UX para WinForms</summary>
<br>

Uma biblioteca em C# desenvolvida para modernizar aplicações em Windows Forms. Projetada para resolver as limitações visuais dos controles padrão, este framework fornece componentes estilizados e reutilizáveis — botões modernos, painéis sem borda, gerenciadores de tema — permitindo que aplicações desktop legadas tenham uma interface contemporânea sem precisar migrar de framework.

| Stack | Arquitetura de Componentes | Impacto de Performance | Repositório |
|---|---|---|---|
| C# / .NET / WinForms | Herança de Controles + Helpers | Zero overhead de runtime | [LouasDev/Louas.UI.Framework](https://github.com/LouasDev/Louas.UI.Framework) |

**Decisões Arquiteturais:** Cada componente herda seu equivalente nativo do WinForms, garantindo compatibilidade total com o Visual Studio Designer e estendendo a renderização via overrides no `OnPaint`. As classes auxiliares são utilitários sem estado (stateless), minimizando o acoplamento e maximizando a portabilidade do código.

</details>

<details>
<summary><strong>Biblioteca Gastão Valle</strong> — Sistema Enterprise de Gerenciamento</summary>
<br>

Um Sistema de Gerenciamento de Biblioteca, desenvolvido inicialmente no curso técnico e posteriormente refatorado para atender aos padrões profissionais de engenharia backend. O projeto serve como vitrine de decisões arquiteturais: modelagem de banco de dados normalizada no SQL Server, separação limpa entre acesso a dados e regras de negócio, e validação robusta.

| Stack | Escala do Banco de Dados | Segurança | Repositório |
|---|---|---|---|
| C# / .NET / SQL Server | Schema relacional normalizado | Queries parametrizadas | [LouasDev/BibliotecaGastaoValle](https://github.com/LouasDev/BibliotecaGastaoValle) |

**Processo de Refatoração:** O objetivo primário foi eliminar o código de acesso a dados fortemente acoplado nas interfaces (event handlers). A nova arquitetura introduz uma camada clara de repositório, uma camada de serviço para regras de negócio e uma de apresentação exclusiva para UI. Consultas SQL foram otimizadas e mapeadas via Entity Framework para evitar problemas como queries N+1.

</details>
